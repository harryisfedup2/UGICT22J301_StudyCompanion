The story behind Java and the JVM

1991 — Green Project. Sun Microsystems began exploring software for small consumer-electronic devices. James Gosling and colleagues designed a language first called Oak, with predictable behavior across different processors and devices as a major goal.

1990s — a change of destination. The consumer-device market did not develop as the team expected. As the public Internet and web browsers grew, the language was retargeted for networked software and renamed Java. The name change was practical as well as legal: Oak was already in use.

1995–1996 — public release. Sun announced Java in 1995; Java 1.0 shipped in 1996. Its promise was “write once, run anywhere” where a compatible Java runtime exists. Java source was compiled to bytecode, then a JVM implemented that bytecode on a particular operating system and processor.

1998–2017 — platform grows. Java 2 brought major libraries and platform editions; Java 5 (2004) added language features including generics and enhanced for-loops; Java 8 (2014) added lambdas and related functional APIs; Java 9 (2017) introduced the module system. Each change had to balance new capabilities with compatibility for existing programs.

The JVM is not merely a “Java interpreter.” The Java Virtual Machine Specification defines a class-file format and execution model. A JVM may interpret bytecode, compile frequently used code to native instructions just in time (JIT), or combine techniques. The Java compiler (javac) turns source into class files; it does not normally compile directly to one processor’s machine code.

Java, the Internet, and C/C++

Language, platform, and Internet

Java the language defines source-code rules and meaning. The Java platform adds the JVM, standard libraries, development tools, and runtime services. The Internet is the global network of interconnected networks; the Web is one service on it, using protocols such as HTTP. Java can create network software, but Java is not the Internet and does not require a browser.

A normal build-and-run path is: Unit1Example.java → javac → Unit1Example.class (bytecode) → JVM → program behavior. A class file is portable only when the destination has a compatible JVM, libraries, and required permissions. Native libraries, operating-system assumptions, and version differences can still reduce portability.

Frequently taught design features

Object-oriented

Programs can model related state and behavior with classes and objects. Java is not “pure OOP”: primitive values such as int are not objects.

Portable and architecture-neutral

Bytecode and specified primitive sizes avoid compiling every ordinary Java class for one CPU. A compatible runtime is still required.

Robust

Static type checks, array bounds checks, exceptions, and managed memory catch or reduce many classes of error. They do not make every program correct.

Managed memory

The garbage collector can reclaim unreachable objects. Programmers still close files, sockets, database connections, and other scarce resources.

Concurrent

Java has a thread model and synchronization rules for tasks that overlap. Concurrency introduces race conditions and needs careful design.

Rich libraries

Collections, I/O, networking, text, time, security, and database APIs let programs reuse tested building blocks.

Object-oriented programming: four core ideas

OOP organizes a program around objects: individual entities that have identity, state (data), and behavior (operations). A class defines a kind of object; an object is one instance created from that class.

Encapsulation

Keep an object’s internal state behind a clear public interface. A bank account protects its balance: customers request a deposit or withdrawal instead of changing the ledger cell directly. In Java, access modifiers such as private and methods enforce that boundary.

Abstraction

Expose the operations a user needs while hiding unnecessary implementation details. A student can call withdraw without knowing how a bank stores transaction records. In Java, methods, interfaces, and abstract classes define useful contracts.

Inheritance

A specialized class reuses and extends behavior from a more general class. A campus vehicle can inherit common registration details from Vehicle, then add bus-specific capacity. Use inheritance for a genuine “is-a” relationship; composition is often better for “has-a.”

Polymorphism

One common operation can lead to different behavior depending on the actual object. A campus map can call arrive() on a Bus or Bicycle object and each can describe its own arrival. Overridden instance methods are selected at runtime by the object’s class.

Complete example: encapsulated account

class BankAccount {
    private final String owner;
    private int balance;

    BankAccount(String owner, int openingBalance) {
        this.owner = owner;
        this.balance = openingBalance;
    }

    public void deposit(int amount) {
        if (amount > 0) balance += amount;
    }

    public int getBalance() {
        return balance;
    }

    public static void main(String[] args) {
        BankAccount account = new BankAccount("Asha", 500);
        account.deposit(150);
        System.out.println(account.owner + " has " + account.getBalance());
    }
}

Line by line: class BankAccount declares a reusable type. private final String owner stores an owner that is chosen at construction and cannot later be reassigned; private int balance hides mutable state. The constructor accepts initial values, and this.owner means “the field belonging to this new object,” distinguishing it from the parameter with the same name. deposit checks a basic business rule before changing the field. getBalance offers controlled read access. main creates one instance, calls its behavior, and prints the result.

Expected output: Asha has 650. This small example does not implement currency rounding, persistence, concurrency control, or a complete banking policy; it demonstrates object state and encapsulation.

Every other Java type is a reference type: class types (including String), interfaces, arrays, and enum types. A reference can point to an object or be null; a primitive variable holds a primitive value. Fields and array elements receive default values, but local variables must be definitely assigned before use.

Variables and initialization

A variable is a named storage location with a declared type. A declaration introduces its name and type; an initialization supplies its first value; an assignment later stores a value. A local variable has block scope, an instance field belongs to each object, and a static field belongs to the class itself.

int attempts;             // declaration
attempts = 1;             // assignment; first assignment initializes this local
final double tax = 0.18;  // initialized once; cannot be reassigned
static int studentCount;  // one class-level field, defaults to 0

Widening and narrowing conversions

A widening primitive conversion generally moves to a type with a larger range, such as int to long; it can be implicit, though floating-point precision may still change. A narrowing conversion, such as double to int, needs a cast because fractional information or range can be lost. Casting does not validate a value.

int count = 12;
double exactAsBinaryFloat = count; // widening
double price = 19.95;
int whole = (int) price;           // narrowing: becomes 19, fractional part is discarded

Unicode and Java characters

Java source text uses Unicode. A char stores one UTF-16 code unit. Many familiar characters fit in one code unit, but some Unicode symbols are represented by a surrogate pair, so one visible symbol can use two char values. For general text processing, use code-point-aware methods such as String.codePoints() when a task means Unicode code points rather than UTF-16 units. A Java Unicode escape such as '\u20B9' can denote the rupee sign; Unicode escapes are processed before ordinary tokenization, which can surprise readers in unusual cases.

Complete operator and Unicode example

class Unit1Values {
    public static void main(String[] args) {
        int credits = 15;
        double fee = 1250.50;
        char rupee = '\u20B9';
        boolean eligible = credits >= 12 && fee > 0;
        int wholeFee = (int) fee;
        int flags = 0b0101;
        int shifted = flags << 1;
        System.out.println("Eligible: " + eligible);
        System.out.println("Fee: " + rupee + wholeFee);
        System.out.println("Shift: " + shifted);
    }
}

Line by line: credits is an integer and fee a double. rupee stores the single UTF-16 unit U+20B9. The comparison operators produce booleans and && combines the conditions with short-circuit logic. The cast intentionally discards the fractional part. 0b0101 is a binary integer literal; shifting it left one place doubles its bit pattern to decimal 10. The print statements join text and values into readable output.

Expected output:
Eligible: true
Fee: ₹1250
Shift: 10

Common errors, comparisons, and applications

  • Using = when testing equality; use == for primitive equality and equals for object content.
  • Assuming 7 / 2 is 3.5; integer operands produce integer division. Write 7.0 / 2 for floating-point division.
  • Forgetting the f suffix on a float literal or L on a large long literal.
  • Expecting a local variable to receive a default value; initialize it before reading.
  • Assuming garbage collection closes a file or database connection. Close those resources explicitly, preferably with try-with-resources.
  • Assuming “portable” means every Java program behaves identically on every device. The runtime, APIs, locale, file system, permissions, and native dependencies matter.
  • Using char or String.length() as a count of user-perceived symbols; UTF-16 code units, code points, and grapheme clusters are different counts.

Java fundamentals are used in desktop and server software, Android applications (with Android-specific APIs and runtime), backend services, data-processing tools, and education. The OOP model is especially useful when a domain has entities with rules and state; procedural or functional styles can be clearer for other problems.

Viva practice · 40 answered questions

1. What is Java?

Java is a general-purpose, statically typed, class-based programming language and a platform ecosystem. Compiled class files execute on a compatible Java virtual machine.

2. Who designed Java?

James Gosling led the original language work at Sun Microsystems, with important contributions from a larger team. The original project name was Oak.

3. What was the Green Project?

It was an early Sun Microsystems effort exploring software for consumer electronic devices. Its language work later became Java.

4. Why did Oak become Java?

The project shifted from its original embedded-device target toward networked software, especially the growing Internet. Oak also could not be used as the product name, so it was renamed Java.

5. What is bytecode?

Bytecode is the instruction set stored in Java class files. It is designed for a virtual machine, rather than one particular processor's native instruction set.

6. What does the JVM do?

The JVM loads and verifies class files, manages runtime execution and memory, and may interpret or JIT-compile bytecode. Its specification defines behavior expected of implementations.

7. What is the difference between JDK, JRE, and JVM?

The JVM executes class files. A runtime environment supplies the JVM and libraries needed to run programs; a JDK adds developer tools such as compilers. Packaging has changed across Java distributions, but the roles remain useful concepts.

8. What does “write once, run anywhere” mean?

It means compatible bytecode can run on different systems that provide a suitable JVM and required libraries. It is a portability goal, not a promise that environment-dependent code will always behave identically.

9. Is Java interpreted or compiled?

Java source is compiled to bytecode. A JVM may interpret bytecode, compile hot methods to native code, or use both approaches.

10. What is the Internet?

It is a global network of interconnected networks that communicate using standard protocols. The World Wide Web is one service carried over the Internet.

11. Is Java a pure object-oriented language?

No. Java supports object-oriented programming, but its eight primitive types are not objects, and static methods can be used without an object instance.

12. Name four OOP principles.

Encapsulation, abstraction, inheritance, and polymorphism. They describe complementary ways to organize state, contracts, reuse, and behavior.

13. Define encapsulation.

Encapsulation keeps data and the operations that control it together, while limiting direct access to internal state. A class can reject invalid changes through its public methods.

14. Define abstraction.

Abstraction presents the essential operations of a component while hiding implementation details that callers do not need. Interfaces and abstract classes can express such contracts.

15. Define inheritance.

Inheritance creates a subclass from a superclass so it can reuse and specialize accessible behavior. It models an “is-a” relationship and should not replace composition when the relationship is “has-a.”

16. Define polymorphism.

Polymorphism lets a common reference or method call work with different object types. Overridden instance methods are selected based on the object's runtime class.

17. What is a class?

A class is a declaration that defines a type's members, such as fields, constructors, and methods. Objects are created as instances of classes.

18. What is an object?

An object is a runtime instance with identity, state, and behavior. Multiple objects of the same class can hold different field values.

19. How does Java differ from C in memory management?

Java automatically reclaims unreachable heap objects through garbage collection. C commonly gives programmers direct allocation and deallocation control; both approaches still require careful resource handling.

20. Does Java support pointer arithmetic?

No ordinary Java source code cannot perform pointer arithmetic. It uses typed references to objects, with access checked by the language and runtime.

21. How does Java differ from C++ inheritance?

A Java class has one direct superclass but can implement multiple interfaces. C++ allows a class to inherit from multiple classes.

22. What is a primitive type?

A primitive type represents a simple value directly, such as an integer, floating-point number, character code unit, or boolean. Java defines eight primitives.

23. List Java's integer types.

byte, short, int, and long. They are signed integer types with widths of 8, 16, 32, and 64 bits respectively.

24. What is the default type of a decimal literal?

A decimal floating-point literal such as 2.5 has type double. Add f or F to write a float literal.

25. What does a Java char store?

A char stores one 16-bit UTF-16 code unit. Some Unicode code points need two char values, so char is not always a whole visible character.

26. What values can boolean hold?

Only true and false. Java does not implicitly convert numeric values to booleans.

27. What is a variable?

A variable is a named, typed storage location used to hold a value. Its scope and lifetime depend on whether it is local, an instance field, or a static field.

28. What is initialization?

Initialization gives a variable its initial value. A local variable must be definitely assigned on every path before it is read.

29. What is a widening conversion?

It converts a value to a type that can generally represent a wider range, such as int to long. Some conversions can still lose precision, particularly integer-to-floating-point conversions of large values.

30. What is narrowing conversion?

It converts to a type with a smaller range or precision and may lose information. Primitive narrowing usually requires an explicit cast.

31. What happens in integer division?

The fractional part is discarded by truncation toward zero. Thus 7 / 2 evaluates to 3, while 7.0 / 2 evaluates as floating point.

32. What does the modulus operator do?

The % operator returns the remainder after division. It is often used for divisibility tests, such as number % 2 == 0 to test evenness.

33. What is operator precedence?

Precedence determines how operators group when parentheses are absent. Parentheses should be used when they make the intended grouping easier to see.

34. What is short-circuit evaluation?

With &&, Java skips the right operand when the left side is false; with ||, it skips the right side when the left side is true. This can prevent unnecessary work or unsafe dereferences.

35. What is the difference between == and equals()?

For primitives, == compares values. For references, it tests whether both refer to the same object; equals is a method commonly overridden to compare content.

36. What does a bitwise shift do?

A shift moves the bits of an integral value left or right. A left shift often multiplies by a power of two when overflow is not a concern.

37. What is Unicode?

Unicode is a standard that assigns code points to characters and symbols across writing systems. Java source and text APIs use Unicode, with char values representing UTF-16 code units.

38. Are Java strings primitive values?

No. String is a reference type and an object. String objects are immutable, meaning their character sequence cannot be changed after creation.

39. What is garbage collection?

Garbage collection reclaims memory for objects that are no longer reachable by a program. It is nondeterministic and does not replace closing external resources.

40. Give two Java applications.

Java is used in server-side business systems and desktop tools, among many others. Java code is also used in Android development, though Android applications run with Android APIs and runtime behavior rather than a standard desktop JVM.
