String construction, operations, extraction, search, and comparison

String is a reference type representing an immutable sequence of UTF-16 code units. Immutable means that methods do not modify the existing String object; operations that appear to change text return another String. Immutability makes strings safer to share, easier to cache, and suitable as map keys when used correctly.

String language = "Java";                 // string literal
String phrase = new String("Study Java"); // explicit construction
char[] letters = {'C', 'o', 'd', 'e'};
String word = new String(letters);        // construct from a char array
String joined = language + " " + word;    // returns a new String

String literals with the same contents may share an interned object. Do not rely on that sharing for content comparison: use equals. The new String(...) constructor is legal but often unnecessary for literals because it creates another object without changing the text.

Character extraction: use charAt for a UTF-16 code unit; getChars copies part of a String into a caller-provided char array; toCharArray creates a new array. If each Unicode code point matters, iterate with codePoints(), because supplementary characters use a surrogate pair.

Searching: indexOf("ava") returns the first starting index or -1. lastIndexOf searches from the end. Searches are case-sensitive unless the program normalizes or uses a dedicated case-insensitive strategy.

Comparing: a == b asks whether the references identify the same object; a.equals(b) asks whether the content is equal. compareTo supports sorting lexically. For locale-aware human-language sorting, use a Collator rather than assuming Unicode code-unit order matches dictionary order.

Wrapper classes and boxing

Each primitive has an object wrapper: Byte, Short, Integer, Long, Float, Double, Character, and Boolean. Wrappers let primitive values be used where an object is required, such as generic collections. Autoboxing converts a primitive to its wrapper; unboxing extracts the primitive value.

Integer boxed = 42;                 // autoboxing
int value = boxed;                  // unboxing
int parsed = Integer.parseInt("73");
Integer objectValue = Integer.valueOf("73");
System.out.println(parsed + value); // 115

parseInt returns primitive int; valueOf returns an Integer. Invalid text can cause NumberFormatException. A null wrapper cannot be unboxed and causes NullPointerException. Wrapper objects are immutable. Use equals for wrapper value equality rather than ==, which compares object identity.

Runtime class and memory management

Runtime represents the running Java application environment. Runtime.getRuntime() returns the process-wide runtime object. Methods can report approximate memory figures, the available processor count, or request garbage collection. Runtime.exec can start an operating-system process, but it requires careful argument, stream, exit-status, and security handling; ProcessBuilder is often clearer. Values such as free memory are snapshots, not reservations or guarantees.

Memory areas, conceptually: each thread has a stack of method frames containing local variables and call state; objects and arrays are generally allocated in the shared heap; class metadata is managed in a runtime area often implemented as metaspace. These are conceptual JVM areas and implementation details can vary. Garbage collection finds unreachable heap objects and reclaims their storage. It does not guarantee when reclamation happens, and it does not close files, sockets, or database connections.

A memory leak in a garbage-collected program can still happen when code unintentionally keeps references to objects it no longer needs (for example, an ever-growing static collection). Close external resources explicitly with try-with-resources. Do not use a call requesting garbage collection as a correctness or timing mechanism.

AWT, layout managers, event handling, and Swing

AWT fundamentals

The Abstract Window Toolkit (AWT) is Java's original desktop GUI toolkit. It provides controls such as Button, Label, TextField, TextArea, Checkbox, Choice, and containers such as Frame and Panel. Many AWT controls use native platform peers (often called heavyweight components), so appearance and behavior can reflect the operating system.

A layout manager calculates component positions and sizes as a container changes. FlowLayout places components in a row and wraps; BorderLayout arranges north/south/east/west/center regions; GridLayout uses equal-sized cells; CardLayout switches among pages; GridBagLayout provides flexible constraints for complex forms. Layout managers adapt better than hard-coded pixel coordinates.

Event delegation

In the event-delegation model, a component is the event source, an event object describes what happened, and a registered listener receives a callback. For example, a button emits an ActionEvent to an ActionListener. An adapter class can provide empty implementations for a listener interface with many methods. Keep callbacks short; long database or network work should happen off the UI thread, then update the UI safely.

Swing

Swing is a richer desktop GUI toolkit built on top of AWT infrastructure. Many Swing components are lightweight and implemented largely in Java, with a pluggable look and feel. Common components include JFrame, JPanel, JLabel, JButton, JTextField, JTextArea, JTable, and JOptionPane. Swing still uses AWT event, graphics, and layout foundations.

Most Swing component creation and updates must happen on the Event Dispatch Thread (EDT). Event listeners run there, so a slow callback can freeze painting and input. Build/show the UI using SwingUtilities.invokeLater; run long work in a background worker and publish results back on the EDT.

import java.awt.FlowLayout;
import javax.swing.JButton;
import javax.swing.JFrame;
import javax.swing.JLabel;
import javax.swing.SwingUtilities;

class SwingHello {
    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            JFrame frame = new JFrame("Course kiosk");
            JLabel message = new JLabel("Ready");
            JButton button = new JButton("Check status");
            button.addActionListener(event -> message.setText("Status checked"));
            frame.setLayout(new FlowLayout());
            frame.add(message);
            frame.add(button);
            frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
            frame.pack();
            frame.setVisible(true);
        });
    }
}

Line by line: imports name the Swing and layout classes. The main method schedules GUI setup on the EDT. A frame is the top-level window; a label displays status and a button emits action events. The lambda is the button's listener; it changes the label in response to the click. FlowLayout positions the controls. The close operation exits the demo, pack sizes the window to its components, and setVisible displays it. Expected visible state: a “Ready” label and a “Check status” button; after clicking, the label reads “Status checked.” The UI itself is interactive, so there is no fixed console output.

JDBC: Java Database Connectivity

JDBC is a standard set of Java interfaces for connecting to relational databases and executing SQL. It separates application code from a specific database vendor's implementation: a JDBC driver translates standard JDBC calls into the database protocol. JDBC does not supply a database server or its driver automatically for every database.

History: early Java lacked a standard database-access API. JavaSoft published the JDBC specification in 1996 as a vendor-neutral framework; the original JDBC 1.0 API became part of JDK 1.1. New API versions followed Java platform releases, adding capabilities while preserving the common connection-and-statement model.

  1. Add a JDBC driver dependency and configure a JDBC URL, credentials, and secure configuration source.
  2. Obtain a Connection using DriverManager or a managed DataSource.
  3. Create a PreparedStatement for parameterized SQL, set parameters, and execute it.
  4. Read query rows through the forward-moving ResultSet cursor.
  5. Close result sets, statements, and connections; try-with-resources is the usual pattern.
  6. For multiple related updates, use a transaction with commit or rollback when needed.

Security: do not concatenate untrusted text into SQL. Use placeholders in PreparedStatement and bind values. This reduces SQL injection risk and lets the driver handle values correctly.

import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.PreparedStatement;
import java.sql.ResultSet;
import java.sql.SQLException;

class JdbcLookup {
    public static void main(String[] args) {
        String url = "jdbc:yourdb://localhost:5432/campus";
        String sql = "SELECT name FROM student WHERE roll_no = ?";
        try (Connection connection = DriverManager.getConnection(url, "app_user", "secret");
             PreparedStatement statement = connection.prepareStatement(sql)) {
            statement.setInt(1, 7);
            try (ResultSet rows = statement.executeQuery()) {
                while (rows.next()) {
                    System.out.println(rows.getString("name"));
                }
            }
        } catch (SQLException problem) {
            System.err.println("Database operation failed: " + problem.getMessage());
        }
    }
}

Line by line: the imports name JDBC interfaces and exception type. The URL identifies a database and location; its exact syntax is driver-specific. The SQL uses a placeholder, not a concatenated roll number. getConnection requires a compatible driver and reachable database. The prepared statement binds roll number 7 to the first placeholder. executeQuery returns rows, and next advances the cursor; getString reads a column. Nested try-with-resources closes the result set, statement, and connection. A SQLException is reported to the error stream.

Expected behavior: if the configured database contains roll number 7, its name is printed; otherwise there are no result lines. If the driver, URL, credentials, or database are unavailable, a clear error is printed. The sample intentionally uses a placeholder URL and credentials and will need a real driver, database, and schema before it can run.

History, applications, and common mistakes

AWT was part of Java's class libraries from the beginning and offered a common GUI API over operating-system widgets. Swing emerged with the Java Foundation Classes and the Java 2 era, adding a broad set of mostly lightweight components and a pluggable appearance. JDBC was standardized in the mid-1990s so Java applications and database vendors could meet through a common interface. These APIs reflect Java's wider design pattern: define contracts and let platform or vendor implementations supply the details.

  • Using == to compare String contents.
  • Assuming String methods mutate the original; they return a result instead.
  • Assuming length() counts user-perceived symbols rather than UTF-16 units.
  • Comparing wrapper objects with ==, or unboxing a nullable wrapper.
  • Calling System.gc() and expecting immediate cleanup.
  • Creating Swing components outside the EDT or doing slow SQL in an event callback.
  • Using absolute pixel positioning when a layout manager would adapt to resizing and font changes.
  • Building SQL by concatenating user input, failing to close resources, or hard-coding real credentials.
  • Assuming JDBC alone supplies a database driver or opens a database service.

Strings and wrappers appear throughout application code. AWT/Swing remain useful for desktop tools, teaching, and legacy systems; they are not Android UI toolkits. JDBC is widely used in server and desktop Java programs; Android applications generally use Android database APIs or a separately configured JDBC driver where appropriate.

Viva practice · 40 answered questions

1. What is a String in Java?

String is a reference type representing an immutable sequence of UTF-16 code units.

2. What does immutable mean?

Once created, the object's character sequence cannot be changed. Operations such as concatenation return a new String value.

3. What is a string literal?

A quoted text value written directly in source code, such as "Java". Literal strings can be interned by the runtime.

4. Why is new String("Java") often unnecessary?

The literal already provides the needed immutable value. The constructor generally creates another String object without changing its contents.

5. What does length() return?

It returns the number of UTF-16 code units in the string, which can differ from the number of Unicode code points or visible symbols.

6. What does charAt do?

It returns the UTF-16 code unit at a zero-based index. The index must be within the String's length.

7. How can String characters be extracted?

Use charAt for one code unit, getChars to copy a range into an array, or toCharArray to make a new char array.

8. How can supplementary Unicode characters be processed?

Use code-point-aware operations such as codePoints() rather than assuming one char equals one character.

9. What does indexOf return when text is absent?

It returns -1. Otherwise it returns the first matching index.

10. Compare indexOf and lastIndexOf.

indexOf searches for the first occurrence from the beginning; lastIndexOf finds the last occurrence.

11. How do you compare String contents?

Use equals for exact content comparison. == compares whether two references identify the same object.

12. What does compareTo return?

A negative, zero, or positive integer indicating lexicographic ordering. Code should test the sign, not depend on an exact nonzero value.

13. Does toUpperCase modify a String?

No. It returns a String with converted text; the original object remains unchanged. Locale can affect case conversion.

14. What is StringBuffer?

It is a mutable character sequence with synchronized methods. It supports edits such as append and insert without replacing the buffer reference.

15. StringBuffer versus String?

String is immutable; StringBuffer is mutable and synchronized. For repeated single-thread text building, StringBuilder is usually the preferred unsynchronized alternative.

16. Is StringBuffer.equals content-based?

No. StringBuffer implements Comparable but does not override equals for text equality. Convert to String or compare its content explicitly.

17. Name Java's wrapper classes.

Byte, Short, Integer, Long, Float, Double, Character, and Boolean are wrappers for the eight primitive types.

18. What is autoboxing?

It is the automatic conversion from a primitive value to its corresponding wrapper object, such as int to Integer.

19. What is unboxing?

It extracts a primitive value from its wrapper object. Unboxing a null reference throws NullPointerException.

20. Difference between parseInt and valueOf?

Integer.parseInt returns an int primitive; Integer.valueOf returns an Integer wrapper.

21. What happens when Integer.parseInt receives invalid text?

It throws NumberFormatException. Validate input or catch that exception when input is untrusted.

22. What is Runtime?

Runtime represents the running Java application environment and provides methods for querying or interacting with that environment.

23. How is the Runtime instance obtained?

Call Runtime.getRuntime(), which returns the runtime object associated with the current Java application.

24. Does freeMemory report a guaranteed amount of available memory?

No. It is an approximate snapshot of currently unused memory in the heap and can change as the runtime allocates or collects objects.

25. What is garbage collection?

It reclaims heap storage occupied by objects that are no longer reachable. It is not deterministic and does not close external resources.

26. Can Java programs have memory leaks?

Yes. Code can keep unnecessary references alive, preventing garbage collection even though the objects are no longer useful.

27. What is AWT?

The Abstract Window Toolkit is Java's original desktop GUI API, with controls, containers, graphics, events, and layout support.

28. Name four AWT controls.

Button, Label, TextField, and TextArea are examples. AWT also provides checkboxes, choices, lists, and other components.

29. What is a layout manager?

It positions and sizes components in a container, adapting to changes such as window resizing or font metrics.

30. What does FlowLayout do?

It arranges components in a row from left to right and wraps them into additional rows when space is limited.

31. What does BorderLayout do?

It divides a container into north, south, east, west, and center regions. The center region receives the remaining space.

32. What is event delegation?

A source component creates an event object and notifies registered listener objects that implement the appropriate callback interface.

33. What is an event listener?

It is an object registered with an event source to receive a callback when an event occurs, such as a button action.

34. What is Swing?

Swing is a richer Java desktop GUI toolkit with many mostly lightweight components and a pluggable look and feel. It builds on AWT infrastructure.

35. What is the Event Dispatch Thread?

The EDT is the thread that processes Swing events and most Swing UI updates. Keeping its tasks short helps the interface remain responsive.

36. What is JDBC?

Java Database Connectivity is a standard Java API of interfaces for connecting to databases and executing SQL through database-specific drivers.

37. What is a JDBC driver?

It implements JDBC interfaces and translates application calls into a specific database protocol. The application must include a compatible driver.

38. What is PreparedStatement?

It represents parameterized SQL with placeholders. Binding values avoids building SQL by concatenating untrusted input and reduces injection risks.

39. What does ResultSet do?

It represents rows returned by a query. Its cursor starts before the first row; call next() to advance and test whether a row exists.

40. Why use try-with-resources in JDBC?

It closes the ResultSet, statement, and connection reliably when the block ends, including when an SQL operation throws an exception.
